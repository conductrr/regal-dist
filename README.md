# regal-dist

Auslieferung der iOS-App **Regal** fuer SideStore. Hier liegt nur die gebaute App,
der Quelltext liegt woanders.

Quelle in SideStore hinzufuegen, unter Sources:

    https://raw.githubusercontent.com/conductrr/regal-dist/main/apps.json

Die `.ipa` haengt an den Releases, nicht im Repo. Jedes Release traegt eine
Bau-Nummer; nur eine groessere Bau-Nummer legt sich auf dem Geraet ueber die
installierte App.

Die App bringt keine Zugangsdaten mit. Anmeldung und Serveradresse werden erst
auf dem Geraet gesetzt.
